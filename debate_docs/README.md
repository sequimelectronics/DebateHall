# debate_docs

The documents being debated go here: a paper (Markdown, `.md`), and its sources in `citations/`.

Nothing in this folder except the READMEs is committed (see `.gitignore`), so a paper that isn't released yet
can't end up in the repository by accident. The chair points a debate at a paper with its path relative to this
folder; the hall records the file's hash, and every line and ruling after that refers to that exact version.
